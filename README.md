# 🧠 Object Detection with YOLOv5

This project demonstrates **real-time object detection** using the pre-trained [YOLOv5](https://github.com/ultralytics/yolov5) model.  
It can detect multiple objects in images, videos, or even live camera streams.

---

## 🚀 Features
- Real-time **object detection** using YOLOv5.
- Works on:
  - 📷 Images
  - 🎥 Video files
  - 📹 Live webcam streams
- Bounding boxes 🟥 and labels are drawn on detected objects.
